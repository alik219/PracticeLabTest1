# Practice provenance

Prepared September 29, 2026 for EECS 3311 B. New PrintDesk domain and synthetic data.
Rehearsal sources: LT1 preparation map; Lab01 validation/boundary testing;
Lab02 collaborator, recorder and immutable detached snapshot; L04 class UML and
L05 message-order explanation. No later named SOLID principle or design pattern.
Run/setup scripts are copies of the existing course Lab01 starter scripts.
Java 21 and cached JUnit 6.0.3 are the course baseline. No live-test paper or private
marking check was used. This is ungraded practice, not the released LT1 starter.

The demo PowerShell scripts use .NET SHA-256 for compatibility where Get-FileHash
auto-loading is unavailable. The pinned digest, commands and validation stay the same.

The demo Git Bash route converts the cached jar path with cygpath before passing
its Windows classpath to javac. Other course commands remain the same.
